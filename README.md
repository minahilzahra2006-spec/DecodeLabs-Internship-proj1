# 🍔 Bun & Bite — Premium Burger Ordering Experience

## Overview
Welcome to **Bun & Bite**, a modern, responsive, and interactive burger restaurant web application created for **DecodeLabs Internship Project 1 (P1)**. Designed with a passion for great food and seamless user experience, Bun & Bite brings a appetizing digital storefront to burger lovers with dynamic shopping features.
Key Features
Delicious Menu Display: High-quality visual showcase of signature burgers, sides, and beverages.

Interactive Add to Cart: Real-time cart management allowing users to easily add, adjust, and view selected items.

Seamless Order Now: Streamlined checkout and order trigger system for a fast ordering experience.

Fully Responsive Design: Pixel-perfect layout optimized across desktop, tablet, and mobile devices.

Fast & Lightweight: Built with clean, performance-optimized HTML, CSS, and JavaScript.

🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript (ES6+)

Styling: Custom CSS Flexbox/Grid with responsive media queries
